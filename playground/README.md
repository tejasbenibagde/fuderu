## 🎮 Playground

> Purpose

This directory is used for locally testing and experimenting with the library during development.

You can run these playgrounds after forking/cloning the repository and installing dependencies.

---

## 📦 Commands

### Vanilla JavaScript (HTML)

Run the plain HTML + Canvas playground:

```bash
npm run playground
```

### Next.js Playground
Move into the Next.js playground directory:
```node
cd playground/nextjs
npm install
npm run dev
```
