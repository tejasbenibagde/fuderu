## Step 1: Setup Your HTML

Start with a basic HTML file that includes a canvas element for drawing:

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>My First Fuderu Canvas</title>
    <style>
      /* Optional: Add some basic styling */
      body {
        font-family:
          -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif;
        margin: 0;
        padding: 2rem;
        background-color: #f8fafc;
      }
      .canvas-container {
        max-width: 800px;
        margin: 0 auto;
        background: white;
        border-radius: 12px;
        box-shadow: 0 4px 6px rgba(0, 0, 0, 0.1);
        overflow: hidden;
      }
      .controls {
        padding: 1rem;
        background-color: #f1f5f9;
        border-bottom: 1px solid #e2e8f0;
        display: flex;
        gap: 1rem;
        flex-wrap: wrap;
        align-items: center;
      }
      .control-label {
        font-weight: 600;
        color: #334155;
      }
      canvas {
        display: block;
        width: 100%;
        height: 500px;
      }
    </style>
  </head>
  <body>
    <div class="canvas-container">
      <div class="controls">
        <div>
          <label class="control-label" for="color-picker">Color:</label>
          <input type="color" id="color-picker" value="#2563eb" />
        </div>
        <div>
          <label class="control-label" for="size-slider">Size:</label>
          <input type="range" id="size-slider" min="4" max="50" value="20" />
          <span id="size-value">20</span>px
        </div>
        <div>
          <label class="control-label">
            <input type="checkbox" id="eraser-toggle" />
            Eraser Mode
          </label>
        </div>
        <button id="clear-btn" class="clear-button">Clear Canvas</button>
      </div>
      <canvas id="drawing-canvas"></canvas>
    </div>

    <!-- Include Fuderu from a CDN for quick testing -->
    <script type="module">
      import { Canvas } from "https://cdn.jsdelivr.net/npm/fuderu@latest/dist/index.esm.js";

      // Get references to your HTML elements
      const canvasElement = document.getElementById("drawing-canvas");
      const colorPicker = document.getElementById("color-picker");
      const sizeSlider = document.getElementById("size-slider");
      const sizeValue = document.getElementById("size-value");
      const eraserToggle = document.getElementById("eraser-toggle");
      const clearBtn = document.getElementById("clear-btn");

      // Initialize Fuderu Canvas
      const painter = new Canvas({
        canvas: canvasElement, // Pass the canvas element directly
        document: {
          width: 1600, // Logical drawing width (high-resolution buffer)
          height: 1000, // Logical drawing height
        },
        brush: {
          color: "#2563eb", // Starting color
          size: 24, // Starting brush size in pixels
          spacing: 0.25, // Space between brush stamps (0-1)
        },
        pressureSimulation: true, // Enable pressure simulation for mouse/touch
      });

      // Update UI when controls change
      colorPicker.addEventListener("input", (e) => {
        painter.loadConfig({ color: e.target.value });
      });

      sizeSlider.addEventListener("input", (e) => {
        const size = parseInt(e.target.value);
        sizeValue.textContent = `${size}px`;
        painter.loadConfig({ size });
      });

      eraserToggle.addEventListener("change", (e) => {
        painter.setEraser(e.target.checked);
        // Optional: Update button appearance
        clearBtn.style.opacity = e.target.checked ? 0.7 : 1;
      });

      clearBtn.addEventListener("click", () => {
        if (confirm("Clear the entire canvas?")) {
          painter.clear();
        }
      });
    </script>
  </body>
</html>
```

## Step 2: Install Fuderu

For production projects, install Fuderu via npm:

```bash
npm install fuderu
# or
yarn add fuderu
# or
pnpm add fuderu
```

For quick prototypes or learning, you can also use a CDN:

```html
<script type="module">
  import { Canvas } from "https://cdn.jsdelivr.net/npm/fuderu@latest/dist/index.esm.js";
</script>
```

## How It Works

Let's break down what's happening in the code:

### The Canvas Initialization

```javascript
const painter = new Canvas({
  canvas: canvasElement, // Connect to your HTML canvas element
  document: {
    // Set the drawing resolution
    width: 1600, // High-resolution buffer for quality
    height: 1000,
  },
  brush: {
    // Configure your brush properties
    color: "#2563eb", // Starting color (blue)
    size: 24, // Starting size in pixels
    spacing: 0.25, // Brush stamp spacing (smoother = lower)
  },
  pressureSimulation: true, // Enable pressure effects for mouse/touch
});
```

### Updating Brush Properties

When you change the color or size:

```javascript
painter.loadConfig({
  color: e.target.value, // Update to selected color
  size: parseInt(e.target.value), // Update to selected size
});
```

### Toggling the Eraser

The eraser doesn't actually erase - it sets the brush to transparent:

```javascript
painter.setEraser(true); // Enable eraser mode (draws with transparency)
painter.setEraser(false); // Disable eraser mode (normal drawing)
```
