## What Makes Fuderu Special?

Fuderu is designed for developers who want to build beautiful drawing experiences without the complexity of heavy graphics libraries. Whether you're building a simple sketch pad, a professional annotation tool, or a creative art application, Fuderu gives you the building blocks you need.

Fuderu 1.5.0 brings a complete, professional artist workstation to the browser: featuring **Selection Tools** (rectangle, ellipse, freehand lasso, and marching ants), **Floating Interactive Transformations** (move, rotate, scale, and flip with live handles), **Cross-Layer & Cross-Document Clipboard Pipeline** (cut, copy, paste), a serializable **Operation Log & Action Replay Stream API** (`action:record`, `stroke:record`, `replay`), first-class **Document Persistence** with automated schema migrations, layer-level **Alpha Lock** and **Layer Lock**, native scanline **flood fill**, shape primitives, raster text, and typed state event subscriptions.

### 🎨 Key Capabilities

Unlike general-purpose canvas libraries, Fuderu combines a **standalone brush engine** with a **full layer compositing stack**, **artist tools**, and **document state system**:

#### ✂️ Artist Tools: Selection, Transform & Clipboard (v1.5.0)

- **Selection Tools**: Rectangular, elliptical, and freehand lasso selections with Boolean combine modes (`replace`, `add`, `subtract`, `intersect`), animated marching ants rendering (`renderSelectionOutline`), and automatic tool clipping.
- **Transform Operations**: Interactive floating transform sessions (`beginTransform`, `commitTransform`, `cancelTransform`) with live resize handles, rotation handle stem, center pivot, and one-shot transformation helpers (`translate`, `rotate`, `scale`, `flipHorizontal`, `flipVertical`).
- **Clipboard Pipeline**: Unified clipboard store (`ClipboardStore`, `copy`, `cut`, `paste`) enabling raster selection and layer region transfers across layers and separate documents, with optional new layer creation, marquee wrapping, and system clipboard interoperability.

#### 📄 Document Persistence API

Export and import complete canvas state as versioned JSON containing dimensions, layer metadata, active selections, and serialized image data (`exportDocument`, `importDocument`), or export flattened PNG composition renders (`exportPNG`). Includes automatic forward schema migration (`migrateDocument`).

#### 🔒 Advanced Layer Stack & Alpha Lock

16 blend modes, opacity, visibility, layer reordering, **Alpha Lock** (restricting drawing/filling to existing non-transparent pixels), and **Layer Lock** (protecting layers against accidental edits or deletions).

#### 🪣 Native Raster Operations & Shapes

Built-in scanline **flood fill** (`floodFill`), vector shape primitives (`drawRectangle`, `drawEllipse`, `drawLine`), raster text rendering (`drawText`), and pixel color sampling (`getColorAt`).

#### ⚡ Reactive Event System & Timeline History

Subscribe to typed state events (`change`, `stroke:start`, `stroke:end`, `layer:change`, `history:change`, `selection:change`, `transform:start`, `clipboard:copy`) with immutable `getSnapshot()`, and navigate history timeline directly with `canvas.history.goTo(index)` or sparse memory patches.

#### 🎬 Action Replay Stream

Record every user interaction as a serializable action log and play it back programmatically at adjustable speeds (`canvas.replay()`), ideal for animated time-lapses, tutorials, or multiplayer canvas synchronization.

#### ✨ Smooth Interpolation & Adaptive Spacing

Natural-looking strokes that connect points intelligently, eliminating jagged lines using Bezier curve algorithms with adaptive brush stamp density for consistent texture at any drawing speed.

#### 🖱️ Pressure Sensitivity & Image Brushes

Real pen pressure support with intelligent mouse/touch simulation, plus PNG/WebP custom stamp tips with recoloring and rotation capabilities.

### 🧩 Built for Integration

Fuderu is deliberately **framework-agnostic** - use it with:

- ⚛️ React
- 💙 Vue
- 💚 Svelte
- 🌐 Vanilla JS/TS
- ⚡ Next.js
- 📄 Plain HTML

## Getting Started in 60 Seconds

Here's the fastest way to see Fuderu in action:

```bash
npm install fuderu
```

```html
<canvas id="my-canvas" style="width: 600px; height: 400px"></canvas>
```

```typescript
import { Canvas } from "fuderu";

const painter = new Canvas({
  canvas: "#my-canvas",
  document: {
    width: 1200,
    height: 800,
  },
  brush: {
    color: "#2563eb",
    size: 24,
    spacing: 0.25,
  },
});

// Start drawing immediately!
// Try changing colors, sizes, or try the eraser mode
painter.loadConfig({
  color: "#dc2626",
  size: 12,
});
```
