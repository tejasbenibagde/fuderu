## 🎮 Playground

> Purpose

This directory is used for locally testing and experimenting with the library during development.

You can run these playgrounds after forking/cloning the repository and installing dependencies.

---

## 📦 Commands

### Vanilla JavaScript

Run the vanilla JavaScript playground:

```bash
npm run vanilla
```

### Next.js Playground

Run the Next.js playground from the repository root:

```bash
npm run next
```
