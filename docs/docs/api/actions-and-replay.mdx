# Actions & Replay API 🎬

Fuderu provides a serializable event log and replay engine for canvas operations.

```typescript
import type { CanvasAction, ReplayOptions } from "fuderu";
```

---

## Canvas Replay Methods

### `getActionLog(): readonly CanvasAction[]`

Returns the array of all serializable actions executed in the current session.

### `replay(actions: CanvasAction[], options?: ReplayOptions): Promise<void>`

Replays an array of actions sequentially on the canvas and waits for each action
to finish. When an action references a layer ID that does not exist on the
destination and is not declared by a `createLayer` action in the replay stream,
it targets the destination's active layer as it was when replay began. Layer IDs
declared by `createLayer` actions are preserved. Include layer-creation actions
in the stream when later actions target those layers.

### `replayAction(action: CanvasAction): Promise<void>`

Replays a single action. Await the returned promise when subsequent work depends
on the action finishing; for strokes, it resolves after queued brush points are
flushed and committed.

### `clearActionLog(): void`

Clears the internal recorded-action log.

## Types

### `CanvasAction`

```typescript
type CanvasAction =
  | StrokeAction
  | FloodFillAction
  | ClearLayerAction
  | DrawRectangleAction
  | DrawEllipseAction
  | DrawLineAction
  | DrawTextAction
  | CreateLayerAction
  | DeleteLayerAction
  | SelectRectangleAction
  | SelectEllipseAction
  | SelectLassoAction
  | SelectAllAction
  | ClearSelectionAction
  | InvertSelectionAction
  | TransformAction
  | CopyAction
  | CutAction
  | PasteAction;
```

### `ReplayOptions`

```typescript
interface ReplayOptions {
  /** Playback speed; 0 (default) skips delays, positive values set inter-action delay */
  speed?: number;
  /** Fixed delay between actions, used when speed is not set */
  delayMs?: number;
  /** Called before each action */
  onAction?: (action: CanvasAction, index: number, total: number) => void;
  /** Called as progress advances; progress is between 0 and 1 */
  onProgress?: (progress: number, current: number, total: number) => void;
}
```

### Resetting artwork before replay

`canvas.resetArtwork(): void` resets the canvas to one empty Background layer,
clears selection and transform state, and clears undo/redo history without
clearing the action log. Use it to replay a saved log from a clean starting
state:

```ts
const actions = painter.getActionLog();
painter.resetArtwork();
await painter.replay(actions);
```
