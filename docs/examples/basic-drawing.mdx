# Basic Drawing Example

This example demonstrates the fundamental concepts of Fuderu: creating a canvas, handling pointer events, and basic drawing.

## Code

```jsx
import React, { useEffect, useRef } from "react";
import { Canvas } from "fuderu";

export default function BasicDrawing() {
  const canvasRef = useRef(null);

  useEffect(() => {
    if (!canvasRef.current) return;

    // Initialize Fuderu canvas
    const painter = new Canvas({
      canvas: canvasRef.current,
      document: {
        width: 800,
        height: 600,
      },
      brush: {
        color: "#2563eb",
        size: 24,
        opacity: 0.8,
        flow: 0.6,
      },
    });

    // Simple drawing example - draw a smiling face
    drawSmileyFace(painter);

    // Cleanup on unmount
    return () => {
      painter.destroy();
    };
  }, []);

  function drawSmileyFace(painter) {
    // Draw face circle
    painter.brush.putPoint(400, 300, 0.5);
    // In a real app, you'd use a proper circle drawing function
    // For demo purposes, we'll just show the concept

    // For this example, we'll just show that we can draw
    // A real implementation would use proper path drawing
  }

  return (
    <div>
      <h2>Basic Drawing Example</h2>
      <p>This example shows how to initialize Fuderu and draw basic shapes.</p>
      <canvas ref={canvasRef} width={800} height={600} />
      <p>
        <em>
          Note: This is a simplified example. See the canvas API documentation
          for full drawing capabilities.
        </em>
      </p>
    </div>
  );
}
```

## Key Concepts Demonstrated

1. **Canvas Initialization**: Creating a Canvas instance with a DOM element and configuration
2. **Basic Configuration**: Setting color, size, opacity, and flow properties
3. **Resource Cleanup**: Properly destroying the Canvas instance when the component unmounts
4. **Drawing Concept**: Showing how to initiate drawing with putPoint
