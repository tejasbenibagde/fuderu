# Fuderu Documentation Guide

This document provides an overview of the Fuderu documentation structure and helps you find the information you need based on your experience level and goals.

## Documentation Structure

The Fuderu documentation is organized into several sections to help you learn and master the library:

### 📚 Getting Started

Perfect for newcomers to Fuderu:

- [Introduction](./intro.mdx) - Overview of what Fuderu is and its main features
- [Quick Start](./getting-started/quick-start.mdx) - Build your first drawing application in minutes
- [Installation](./getting-started/installation.mdx) - How to install and set up Fuderu in your project

### 🛠️ Core Concepts

Fundamental building blocks of Fuderu:

- [Canvas API](./api/canvas.mdx) - High-level wrapper with event handling and layer management
- [Brush API](./api/brush.mdx) - Low-level stroke engine for custom integrations
- [Configuration](./api/configuration.mdx) - Brush settings and customization options
- [Layer System](./api/layers.mdx) - Non-destructive editing with blend modes and layer management

### 🎨 Advanced Features

Powerful extensions to enhance your drawing applications:

- [Modules](./guides/modules.mdx) - Extend brush behavior with dynamics, scattering, transparency, and patterns
- [Image Brushes](./guides/image-brushes.mdx) - Use custom images as brush tips
- [Performance](./guides/performance.mdx) - Optimization techniques for smooth drawing experiences

### 🧩 Framework-Specific Guides

Tailored instructions for popular frontend frameworks:

- [React Integration](./guides/integration-react.mdx) - Hooks, component patterns, and performance tips
- [Vue 3 Integration](./guides/integration-vue.mdx) - Composables, provide/inject, and SSR considerations
- [Svelte Integration](./guides/integration-svelte.mdx) - Stores, component patterns, and reactivity practices

### 📖 Reference Documentation

Detailed API references:

- [Modules API Reference](./guides/modules.mdx) - Complete module interface documentation
- [Type Definitions](./api/modules.mdx) - All TypeScript interfaces and types

### 💡 Examples & Inspiration

Ready-to-run examples showcasing different capabilities:

- [Basic Drawing](../examples/basic-drawing.mdx) - Getting started with core functionality
- [Brush Modules](../examples/modules-demo.mdx) - Creating expressive brushes with dynamics and scattering

## Learning Paths

### For Complete Beginners

1. Start with [Introduction](./intro.mdx)
2. Follow the [Quick Start](./getting-started/quick-start.mdx) guide
3. Learn the [Canvas API](./api/canvas.mdx) and [Brush API](./api/brush.mdx)
4. Experiment with the [Basic Drawing Example](./examples/basic-drawing.mdx)
5. Explore [Modules](./guides/modules.mdx) to enhance your brushes

### For Framework Developers

1. Begin with [Installation](./getting-started/installation.mdx)
2. Review [Quick Start](./getting-started/quick-start.mdx) for core concepts
3. Go to your framework's specific guide:
   - [React Integration](./guides/integration-react.mdx)
   - [Vue 3 Integration](./guides/integration-vue.mdx)
   - [Svelte Integration](./guides/integration-svelte.mdx)
4. Check out framework-specific examples in the examples directory

### For Advanced Users

1. Master the [Brush Configuration](./api/configuration.mdx)
2. Dive deep into [Modules](./guides/modules.mdx) and [Advanced Modules](./guides/modules-advanced.mdx)
3. Optimize with [Performance Guide](./guides/performance.mdx)
4. Create custom modules using the [Module Development Guide](./guides/modules-advanced.mdx#developing-custom-modules)
5. Study the [Examples](./examples/) for inspiration
