# Fuderu Documentation Guide

This document provides an overview of the Fuderu documentation structure and helps you find the information you need based on your experience level and goals.

## Documentation Structure

The Fuderu documentation is organized into several sections to help you learn and master the library:

### 📚 Getting Started

Perfect for newcomers to Fuderu:

- [Introduction](/docs/intro) - Overview of what Fuderu is and its main features
- [Quick Start](/docs/getting-started/quick-start) - Build your first drawing application in minutes
- [Installation](/docs/getting-started/installation) - How to install and set up Fuderu in your project

### 🛠️ Core Concepts

Fundamental building blocks of Fuderu:

- [Canvas API](/docs/api/canvas) - High-level wrapper with event handling and layer management
- [Brush API](/docs/api/brush) - Low-level stroke engine for custom integrations
- [Configuration](/docs/api/configuration) - Brush settings and customization options
- [Layer System](/docs/api/layers) - Non-destructive editing with blend modes and layer management

### 🎨 Advanced Features

Powerful extensions to enhance your drawing applications:

- [Modules](/docs/guides/modules) - Extend brush behavior with dynamics, scattering, transparency, and patterns
- [Image Brushes](/docs/guides/image-brushes) - Use custom images as brush tips
- [Performance](/docs/guides/performance) - Optimization techniques for smooth drawing experiences

### 🧩 Framework-Specific Guides

Tailored instructions for popular frontend frameworks:

- [React Integration](/docs/guides/integration-react) - Hooks, component patterns, and performance tips
- [Vue 3 Integration](/docs/guides/integration-vue) - Composables, provide/inject, and SSR considerations
- [Svelte Integration](/docs/guides/integration-svelte) - Stores, component patterns, and reactivity practices

### 📖 Reference Documentation

Detailed API references:

- [Modules API Reference](/docs/guides/modules) - Complete module interface documentation
- [Type Definitions](/docs/api/modules) - All TypeScript interfaces and types

### 💡 Examples & Inspiration

Ready-to-run examples showcasing different capabilities:

- [Editor Demo](/editor) - Try the interactive layer-based editor
- [Quick Start](/docs/getting-started/quick-start) - Build your first drawing app

## Learning Paths

### For Complete Beginners

1. Start with [Introduction](/docs/intro)
2. Follow the [Quick Start](/docs/getting-started/quick-start) guide
3. Learn the [Canvas API](/docs/api/canvas) and [Brush API](/docs/api/brush)
4. Experiment with the [Editor Demo](/editor)
5. Explore [Modules](/docs/guides/modules) to enhance your brushes

### For Framework Developers

1. Begin with [Installation](/docs/getting-started/installation)
2. Review [Quick Start](/docs/getting-started/quick-start) for core concepts
3. Go to your framework's specific guide:
   - [React Integration](/docs/guides/integration-react)
   - [Vue 3 Integration](/docs/guides/integration-vue)
   - [Svelte Integration](/docs/guides/integration-svelte)

### For Advanced Users

1. Master the [Brush Configuration](/docs/api/configuration)
2. Dive deep into [Modules](/docs/guides/modules) and [Advanced Modules](/docs/guides/modules-advanced)
3. Optimize with [Performance Guide](/docs/guides/performance)
4. Explore the [Editor Demo](/editor) for inspiration
